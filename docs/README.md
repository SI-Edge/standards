# Project Web Page Source

This folder is the source of the GitHub Pages site at https://si-edge.github.io/standards/. It is built by GitHub Pages with Jekyll from the `docs/` folder on `main`.

- Brand strings (project name, title, repository URL, maintainer) live in `_config.yml`, so a rename needs changes there and in `index.md` table entries only.
- The layout uses no external scripts, fonts, analytics, or cookies, and sets a strict Content-Security-Policy.
